# Module 1 --- Property Tax Revenue

## Purpose

Estimate annual property-tax revenue generated by a Lagom community.

## Calculation

``` text
Gross Market Value = Homes × Average Sale Price

Gross Assessed Value
= Gross Market Value × Assessment Ratio

Annual Property Tax
= Gross Assessed Value × (Total Applicable Millage / 1,000)
```

Applicable millage can include county, state, school, fire/EMS,
municipal, and other levies.

## Sensitivity Analysis

Module 1 includes:

-   No-abatement/gross case
-   5-year phase-in
-   PILOT scenario
-   Home-count and home-price sensitivity

## Output

`outputs/module1_property_tax.xlsx`

Sheets include:

-   `Inputs`
-   `Property_Tax_Results`
-   `Tax_Breakdown`
-   `Abatement_Sensitivity`
-   `Home_Price_Sensitivity`

# Module 2 --- Sales Tax Uplift

## Purpose

Estimate the annual sales-tax uplift generated by new Lagom households.

The module combines county household-income data from the U.S. Census
ACS with household expenditure data from the BLS Consumer Expenditure
Survey (CE). It estimates household spending, applies a taxable-spending
assumption, and calculates the state, county, and local sales-tax
components generated by a Lagom community.

## Data Sources

The module uses:

``` text
data/acs_b19001_all_counties.csv
data/cu-income-quintiles-before-taxes-2024.xlsx
data/county_inputs.xlsx
```

### Census ACS B19001

ACS table B19001 provides the household-income distribution for each
county.

The model uses:

``` text
B19001_001E = Total households
B19001_002E through B19001_017E = Households by income band
```

The `E` fields are ACS estimates. Margin-of-error (`M`) fields are not
currently used.

### BLS Consumer Expenditure Survey

The model uses the 2024 BLS Consumer Expenditure Survey
income-before-tax quintiles.

  BLS Quintile     Average Annual Expenditure
  -------------- ----------------------------
  Q1                                 \$35,046
  Q2                                 \$50,054
  Q3                                 \$66,900
  Q4                                 \$89,972
  Q5                                \$150,342

Income boundaries used:

  Quintile   Income Range
  ---------- ---------------------
  Q1         Below \$29,932
  Q2         \$29,932--\$57,451
  Q3         \$57,452--\$94,510
  Q4         \$94,511--\$155,924
  Q5         \$155,925+

## ACS-to-BLS Income Mapping

ACS B19001 contains 16 household-income bands, while the BLS expenditure
data contains five income quintiles.

When an ACS band crosses a BLS quintile boundary, households are
allocated proportionally between the applicable quintiles. This assumes
household income is uniformly distributed within the ACS band.

Example for the ACS `$50,000–$59,999` band:

``` text
Q2 fraction
= (57,452 - 50,000) / (60,000 - 50,000)
= 74.52%

Q3 fraction
= 25.48%
```

The `$200,000+` ACS category is assigned to BLS Q5.

## Weighted Annual Household Spending

``` text
Weighted Annual Spending per Household
= SUM(Households in Quintile × BLS Annual Spending for Quintile)
  / Total County Households
```

Current Sedgwick County result:

``` text
ACS Total Households = 206,768
Mapped Households = 206,768
Weighted Annual Spending per Household = $74,230.39
```

## Taxable Spending Assumption

The Lagom methodology suggests approximately 28%--35% of household
spending may be taxable after exemptions.

The current base case uses:

``` text
Taxable Share = 32%
```

For Sedgwick:

``` text
Taxable Spending per Household
= $74,230.39 × 32%
= $23,753.72
```

The 32% value is a modeling assumption. A sensitivity analysis can use
28% as the low case, 32% as the base case, and 35% as the high case.

## Community Taxable Spending

For 150 Lagom homes:

``` text
Community Taxable Spending
= $23,753.72 × 150
= $3,563,058.60 per year
```

## Sales Tax Rates

Sales-tax rates are read from `county_inputs.xlsx`.

Current Sedgwick scenario:

  Component                 Rate
  ---------------------- -------
  State Sales Tax          6.50%
  County Sales Tax         1.00%
  City/Local Sales Tax     0.00%
  Combined Sales Tax       7.50%

The model validates that the state, county, and local components equal
the combined rate.

## Gross Sales Tax Generated

``` text
Gross Community Sales Tax
= Community Taxable Spending × Combined Sales Tax Rate

= $3,563,058.60 × 7.50%
= $267,229.40 per year
```

Gross sales tax per Lagom household is approximately `$1,781.53` per
year.

## Sales Tax Components

  Component                          Estimated Annual Amount
  -------------------------------- -------------------------
  State Sales Tax Component                     \$231,598.81
  County Sales Tax Component                     \$35,630.59
  City/Local Sales Tax Component                      \$0.00
  **Gross Sales Tax Generated**             **\$267,229.40**

County component:

``` text
County Sales Tax Component
= Community Taxable Spending × County Sales Tax Rate
= $3,563,058.60 × 1.00%
= $35,630.59 per year
```

## County-Retained Revenue

The current model reports the county sales-tax component separately from
confirmed county-retained fiscal benefit.

For Sedgwick:

``` text
County Sales Tax Component = $35,630.59/year
```

This amount is based on the county sales-tax rate in
`county_inputs.xlsx`. It should not automatically be labeled final
county-retained revenue unless the applicable state/county distribution
or revenue-sharing rules confirm that the county retains the full
amount.

## Key Assumptions

-   Household income is uniformly distributed within ACS income bands
    when a band crosses a BLS quintile boundary.
-   BLS 2024 CE quintile spending is used as the household expenditure
    proxy.
-   32% of annual household expenditure is taxable in the base case.
-   The current Lagom scenario contains 150 occupied households.
-   Sales-tax rates are supplied through `county_inputs.xlsx`.
-   County sales-tax components remain separate from confirmed
    county-retained revenue until jurisdiction-specific distribution
    rules are validated.

## Reproducibility

The Module 2 methodology is designed to be reused across counties.
County/state selection determines the corresponding ACS income
distribution, while applicable sales-tax inputs are read from
`county_inputs.xlsx`.

The calculation methodology therefore does not need to be rewritten for
each priority county.

# Module 3 --- School System Impact

## Purpose

Estimate the fiscal effect of additional students generated by the Lagom
community.

## Student Estimate

Current 150-home Sedgwick scenario:

``` text
3BD/2BA homes = 90
2BD/2BA homes = 60

Student rate for 3BD = 0.6
Student rate for 2BD = 0.2
```

Therefore:

``` text
New Students
= (90 × 0.6) + (60 × 0.2)
= 66
```

The 60% 3BD / 40% 2BD product mix is currently a scenario assumption
pending confirmation.

## NCES F-33 Data

The model reads:

`data/sdf24_1a.txt`

The district is matched using State + School District name.

Important F-33 fields:

  Field        Purpose
  ------------ ----------------------------------------------------
  `LEAID`      NCES district identifier
  `V33`        Fall membership / enrollment
  `TSTREV`     Total state revenue
  `TCURELSC`   Current elementary/secondary operating expenditure

Derived values:

``` text
State Revenue per Pupil = TSTREV / V33

Operating Cost per Pupil = TCURELSC / V33
```

`TSTREV / V33` is treated as the F-33 state-revenue-per-pupil proxy for
the syllabus's per-pupil state-aid input.

## School Fiscal Calculation

``` text
State Aid Received
= New Students × State Revenue per Pupil

Marginal Cost
= New Students
  × Operating Cost per Pupil
  × (1 - Capacity Discount)

Net School Impact
= State Aid Received - Marginal Cost
```

## Capacity

``` text
Capacity Utilization
= Current Enrollment / District Capacity
```

The model reports district capacity, capacity utilization, capacity
status, over-capacity flag, capacity discount, marginal cost, and net
school impact.

## 85% vs. 110% Capacity Sensitivity

The Sedgwick sensitivity analysis tests two hypothetical capacity
conditions:

  Scenario          Capacity Utilization   Capacity Discount Over Capacity
  --------------- ---------------------- ------------------- ---------------
  85% Capacity                       85%                 90% No
  110% Capacity                     110%                  0% Yes

The numerical capacity discounts are **sensitivity-scenario
assumptions**. They are not presented as NCES values or as numerical
discount values supplied by the Lagom syllabus.

Current Sedgwick sensitivity results:

  ----------------------------------------------------------------------------
  Scenario      New Students  State Revenue   Marginal Cost  Net School Impact
  ----------- -------------- -------------- --------------- ------------------
  85%                     66    \~\$830,607     \~\$105,601   **\~+\$725,007**
  Capacity                                                  

  110%                    66    \~\$830,607   \~\$1,056,006   **\~-\$225,398**
  Capacity                                                  
  ----------------------------------------------------------------------------

This demonstrates that the modeled school fiscal impact is sensitive to
available district capacity.
